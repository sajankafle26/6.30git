Ensure the following while logging in
  1. NIMB OTP ensures Optimum Transaction Security through Two-Factor Authentication using One Time Password (OTP). NIMB OTP service has been activated from July 30, 2016.
  2. URL address on the address bar of your internet browser begins with https://www.nibl.com.np (https stands for secured website)
  3. Do not enter login or other sensitive information in any pop up window
  4. You have verified the security certificate by clicking on the padlock icon of your internet browser
  5. NIMB never asks you to change security details through email, SMS etc.
